# Clipmagic

Clipmagic is an automated and simplified short-form video editor, which works directly in your browser !

## Features

Several templates:
  - Reddit stories
  - SMS Animations
  - AI Stories
  - more soon

## Tech Stack

- NextJS
- [Remotion](https://www.remotion.dev/) (_Make videos programmatically._)
- TailwindCSS

## Installation

```bash
git clone https://github.com/Gustqve/clipmagic/tree/main
cd clipmagic
npm install
```

## Start

```bash
npm start
```
