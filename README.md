# Clipmagic

Clipmagic is an automated and simplified short-form video editor, which works directly in your browser !

## Preview

<div align="center">
<img src="https://raw.githubusercontent.com/GDeremaux/clipmagic/refs/heads/main/public/misc/clipmagic%20screenshot.png" width="500">
</div>

## Features

Several templates:
  - Reddit stories
  - SMS Animations
  - AI Stories
  - more soon

## Installation

```bash
git clone https://github.com/Gustqve/clipmagic/tree/main
cd clipmagic
npm install
```

## Start

```bash
npm start
```

## Tech Stack

- NextJS
- [Remotion](https://www.remotion.dev/) (_Make videos programmatically._)
- TailwindCSS
